A working native macOS file-search app with SQLite persistence, filesystem change tracking, offline catalogues, grouped search expressions, previews, Finder actions, bookmarks, and global shortcut.

Download **Anyseek-macos.zip**, extract it, and move Anyseek.app to Applications. Requires macOS 13+. Universal binary for Apple Silicon and Intel.

This build passed search/database unit tests, filesystem lifecycle integration checks, native window rendering, universal-architecture checks, and ad-hoc signature verification. It is not Apple-notarized; macOS may require Privacy & Security → Open Anyway. Everything feature parity and million-file performance are not claimed. See README for current limits.
